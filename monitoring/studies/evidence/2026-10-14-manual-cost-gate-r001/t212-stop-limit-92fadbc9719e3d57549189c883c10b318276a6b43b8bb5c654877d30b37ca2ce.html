Stop Limit Orders

They combine the features of a Stop and a Limit Order. You set both a Stop and a Limit price. When the Stop price is reached, the order is converted into a Limit order. Then, the new Limit order will be executed once it reaches its target or a better price. 

Why do investors use Stop Limit orders?

 

These orders are intended to protect you from market gaps. The limit and stop target prices set a range of execution. If this range is surpassed, the order will remain pending until the market price returns to your desired levels. 

Investors use a Stop-Limit to minimise potential losses or protect their profit in case the stock moves in the wrong direction. Once activated, Limit orders will execute only if a specified price it met for trade-in full, ceasing if the price turns unfavourable. 

What is the principle behind setting a Stop-Limit? 

 

Buy

The Stop price should be above the current market price of the security and below the Limit price.

Sell 

The Stop price should be below the current market price of the security and above the Limit price. 

How do I set a Stop-Limit BUY order?

 
  1. Tap to 'Buy' a share;
  2. Select the 'Stop Limit' Order type;
  3. Select the Number of Shares;
  4. Set the Stop Price. The price should be above the current price to convert the order into a Limit order;
  5. Set the maximum Limit price you are willing to pay for your share.

  

The execution of the order will depend first on the 'Stop Price, and thereafter on the 'Limit'. 

How do I set a Stop-Limit SELL order?

 
  1. Tap on 'Sell';
  2. Select the 'Stop Limit' Order type;
  3. Select Number of Shares;
  4. Set the Stop Price. The price should be below the current price to convert the order into a Limit order;
  5. Set the minimum Limit Price for which you are willing to sell a share. 

The execution of the order will depend first on the 'Stop Price' and, therefore, on the 'Limit'. 

📄 Note

The order will remain pending, and the funds needed for its execution will be blocked until the price is reached. It cannot be modified unless cancelled and replaced by a new order of the same or a different type.
