# Implementation and acceptance record

Implemented on 6 October 2026 in the user-selected local hub.

## Workspace components

AGENTS.md is the concise entry point. methodology/current.json selects the approved 1.0.0 research specification and records its hash. The original Word methodology was normalised with generic company inputs; the old pasted chat was not copied. Permanent principles, research/evidence/review workflows and copyable full/focused/comparison/update requests are separate.

Company archives use legal-entity folders and dated run versions. run.json preserves the request, security, dates, methodology, gaps, assumptions, review findings, checks and continuation. Sources retain identities, original documents or limited extracts, locations, hashes and explicit read status. observations.json preserves periods, scopes, currencies, source units and conversions. model.json and reviewed-results.json hold reproducible workings. Company indices distinguish published research from unfinished runs. Publication creates immutable hashes; updates create a new run rather than overwrite history.

Supporting utilities provide explicit dated financial arithmetic, evidence comparability, attributed extraction, reviewed report rendering and visible formula-driven workbooks. They do not choose forecasts or generate investment judgements. The spreadsheet helper's operating pattern supports five explicit forecast periods; other sectors and longer transitions require separately validated construction. No database, service, paid data source, external LLM pipeline, screening, scheduled monitoring, application or trading system was built.

## Validation completed

- 43 unit checks cover cumulative-period arithmetic, missing data, currency/scope/period conflicts, amendments/as-of selection, dated distributions/returns, ownership and repurchases, funding, terminal conditions, bank economics, source integrity and immutable/versioned lifecycle behaviour.
- Three pilot workbooks retain formulas and recalculate after export/import through the bundled engine. Operating cases reproduce the separate Python calculation; input changes affect results and do not alter actuals. A deleted required input withholds the value. Sensitivity's Base combination reproduces the active valuation.
- All exported workbook cached cells were inspected independently for common formula errors and required formulas. Historical input cells match the recorded observations.
- APP's standalone thesis is three readable pages. The full report begins with the same text and includes clickable source citations. PDFs were rendered and reviewed page by page.
- JPM tests a tangible-equity substitution and explains why regulatory capital/distribution constraints prevent a generic bank-return conclusion. Unilever tests compatible IFRS scope, re-presented history and GBp/GBP/EUR conversion with missing inputs preserved.
- Controlled fixtures reject pre-revenue/loss perpetuities without positive sustainable terminal earnings, missing burn, unfunded paths and unsupported reconciliation.
- A file-only reconstruction verifies the method/hash and the run records required to resume. This is not a claim that a separate live chat was launched or the folder was automatically registered as an app project.
- Inspected Trading Shadow Agent files retain their original hashes. Its market-driven blends and speculative reconciliation were not adopted.
