Two minimal rule improvements

Scope every validation label to what was actually captured. Each "validated" label should name the source format (PDF, page image, extracted text, partial export) and the parts that were checked. "Fully validated" should need complete capture. Figures that depend on layout, such as which column a number sits in, stay unresolved if only extracted text is available. This closes A and C, and also covers B's "independent test" claim.

Reserve quota for work already in flight. Change "stop at 1%" to: save a checkpoint before starting any step, or waiting on any queued response, that could take remaining quota to 1% or below. Record unfinished external responses as pending, not as cancelled or finished. This closes D's gap, where 2% is above the stop line but a queued response could still take it past.

Case E is already covered by keeping research, allocation and execution separate. An optional clarification: "paper fills require an executable quote at decision time."
