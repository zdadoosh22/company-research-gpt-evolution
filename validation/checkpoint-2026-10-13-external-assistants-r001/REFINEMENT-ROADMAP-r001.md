# External-assistant refinement plan

13 October 2026. This is a bounded workflow plan, not implementation authority for account grants, paid services, monitoring changes or trades. Read with the existing monitoring improvement roadmap; do not create a parallel portfolio policy.

1. **Make the next delegation earn its overhead.** Choose a particular missing fact or falsifiable criticism. Provide one compact packet and clear representation/definition requirements. Skip tasks that merely restate already reviewed evidence. Accept an honest bounded failure and park rather than retry unchanged inaccessible sources. Preserve adverse results and avoid quota-exhaustion targets as success measures.
2. **Validate the proposed role.** Criticism and source discovery are usable provisionally now, not proven reliable. Test a new relevant case without supplying the answer; retain first attempts, access limits and verification effort. Material source/currency/period errors remain blocking for affected findings even if a correction is easy. Escalate the specific weakness rather than weakening review. Actual required Astra challenges remain independent.
3. **Measure coordination fairly.** Record coarse account allowance observations and the actual work between them, including verification and correction overhead. Distinguish rounded or delayed external metering and shared-account activity. No per-task savings percentage can be inferred from this initial trial. Prefer smaller transfers and completion captures; never reduce verification to improve a usage statistic.
4. **Only test coding for a real pending defect.** First verify the supported local Antigravity route and technically scoped access. Use an isolated checkout/worktree, specific files and concrete expected behaviour; inspect proposed commands, final changes and meaningful checks. A no-tools prompt or No Project label is not a sandbox. No useful defect has been assigned yet, so no code-automation readiness is claimed.
5. **Keep Notion optional.** Current free responses are exhausted. Do not poll for renewal, open unrelated content, start a trial or pay. If an existing allowance legitimately becomes available, use a minimal supplied working copy for synthesis with traceable inputs and compare its useful output with coordination cost. Local research remains authoritative.
6. **Advance research rather than the approval label.** Current/disclosed funding and claims, same-basis dated expectations, recurring per-claim changes and plausible value after manual delay must precede an accepted opportunity. The next evidence step should name which specific blocked conclusion it could change. Preserve rejections, missing observations and no-repricing/adverse cases; do not retrospectively invent a successful trade.
7. **Keep delivery and execution acceptance separate.** Phone receipt/acknowledgement, standing-order reconciliation, broker eligibility, executable-price/FX/fee freshness and actual outage recovery still require their own evidence. External assistants do not close these by suggesting an API or describing a test. No paid data, extra contributions, order access or live activation follows this plan.

Completion criteria are concrete evidence records and scoped dispositions, not exhausting all assistant allowances or reaching general project-wide confidence. The current setup and six-case check can be handed to Chat without a new goal. Future assignments remain bounded and must preserve the user's1%Work margin and no-credit constraint.
